# Taco Hunt

Aplicación para descubrir puestos de tacos y calificar tipos de taco específicos en Monterrey.

La especificación funcional del proyecto está en [BUILD_SPEC.md](BUILD_SPEC.md). La landing inicial está en [index.html](index.html) y usa el logotipo [taco-hunt-logo.svg](taco-hunt-logo.svg).

## Alcance inicial

- Aplicación móvil Expo / React Native
- API REST con NestJS y Fastify
- PostgreSQL y Supabase local
- Sitio estático de presentación

Consulta `BUILD_SPEC.md` para las decisiones de arquitectura y requisitos detallados.
